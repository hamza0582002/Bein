# Maktabate — مكتبتي

قارئ كتب احترافي يعرض مكتبتك كما لو كانت رفوفًا حقيقية: الكتب واقفة بكعوبها إلى
الخارج، تنقر على الكعب فيخرج الكتاب ويستدير ليواجهك بغلافه، ثم ينفتح الغلاف على
مفصله وتبدأ القراءة في صفحتين مفتوحتين تُقلَّبان بحركة انثناء ثلاثية الأبعاد.

يعمل التطبيق كاملًا داخل جهازك: لا حساب، ولا خادم، ولا يغادر أي كتاب أو ملاحظة
جهازك. متاح كتطبيق ويب (PWA) وكتطبيق أندرويد (APK).

---

## الميزات

**المكتبة**
- رفوف خشبية ثلاثية الأبعاد: سماكة كل كتاب تتبع طوله، وارتفاعه يختلف عن جاره،
  وآخر كتاب في الصف يميل كما تميل الكتب الحقيقية.
- لون الكعب مشتق من عنوان الكتاب، فيبقى ثابتًا وتتعرّف على كتبك بألوانها.
- منصّة عرض الكتاب: يستدير الكتاب من وضع الرفّ إلى الغلاف، ويمكن سحبه بالفأرة
  لتقليبه من كل زواياه.
- ثلاثة عروض: الرفوف، شبكة الأغلفة، وقائمة تفصيلية.
- تصفية حسب (قيد القراءة / المفضّلة / المكتملة / لم تُقرأ)، مجموعات، وسوم، بحث،
  وترتيب حسب العنوان أو المؤلف أو آخر فتح أو نسبة القراءة.
- بطاقة «تابع القراءة» لآخر كتاب فتحته.
- إضافة الكتب بالسحب والإفلات، مع كشف التكرار عبر بصمة SHA-256 للملف.

**القراءة**
- صيغ مدعومة: EPUB 2/3، PDF، TXT، Markdown، HTML.
- تقسيم إلى صفحات بأعمدة CSS مع حركة تقليب واقعية (ورقة تدور على مفصلها ولها
  وجهان وظِلّ متحرّك)، أو انزلاق أو تلاشٍ أو بلا حركة.
- صفحة واحدة، أو صفحتان كالكتاب المفتوح، أو تمرير متواصل — والتبديل التلقائي
  إلى صفحة واحدة على الشاشات الضيقة.
- أربع سمات (نهاري، ورقي، ليلي، داكن عميق)، وتحكّم في الخط وحجمه وتباعد الأسطر
  والهوامش وضبط النص، إضافة إلى السطوع ودفء الإضاءة.
- صوت تقليب الورق مُولَّد لحظيًا عبر Web Audio (بلا ملفات صوتية).
- تظليل بأربعة ألوان + تسطير، ملاحظات مرتبطة بالمقاطع، وعلامات مرجعية.
- بحث داخل الكتاب يتجاهل التشكيل ويوحّد الألف والياء والتاء المربوطة.
- قراءة صوتية تُضيء الكلمة المنطوقة وتقلّب الصفحات وتنتقل بين الفصول.
- حفظ الموضع بدقّة الحرف، فلا يضيع مكانك عند تغيير حجم الخط أو الشاشة.
- اختصارات لوحة مفاتيح، وضع تركيز، وملء الشاشة.

**الإحصاءات والبيانات**
- أيام القراءة المتتالية، زمن اليوم والأسبوع والإجمالي، صفحات مقروءة، هدف يومي،
  وخريطة حرارية لسنة كاملة.
- تصدير واستيراد نسخة احتياطية (ملاحظات، تظليلات، مواضع القراءة، الإعدادات).
- واجهة عربية أولًا مع دعم كامل لـ RTL، وإمكانية التبديل إلى الإنجليزية.

## التشغيل

```bash
npm install
npm run dev        # خادم تطوير على http://localhost:5173
npm run build      # نسخة إنتاج في dist/
npm run preview    # معاينة نسخة الإنتاج
```

المتطلبات: Node.js 18 فأحدث. لتوليد الأيقونات من جديد تحتاج Python مع Pillow
(`pip install pillow`) ثم `npm run icons`.

## بناء ملف APK

التطبيق مغلّف بـ [Capacitor](https://capacitorjs.com)، ومشروع أندرويد موجود في
مجلد `android/`.

### عبر GitHub Actions (الأسهل)

ملف `.github/workflows/android.yml` يبني الملف عند كل دفعة إلى المستودع:

1. افتح تبويب **Actions** في المستودع.
2. اختر **Build Android APK** ثم آخر تشغيل ناجح.
3. نزّل الأرشيف **Maktabate-apk**، وبداخله:
   - `Maktabate-debug.apk` — جاهز للتثبيت مباشرة.
   - `Maktabate-release.apk` — نسخة الإصدار، موقّعة.

الإصدار يُوقَّع بمفتاح المستودع إن أضفت هذه الأسرار في
Settings → Secrets → Actions، وإلا يُولَّد مفتاح مؤقّت لتلك البناء:

| السرّ | الوصف |
| --- | --- |
| `ANDROID_KEYSTORE_BASE64` | ملف `.jks` مُرمَّز بـ base64 |
| `ANDROID_KEYSTORE_PASSWORD` | كلمة مرور المخزن |
| `ANDROID_KEY_ALIAS` | اسم المفتاح |
| `ANDROID_KEY_PASSWORD` | كلمة مرور المفتاح |

> ملاحظة: تحديث تطبيق مثبَّت يتطلّب التوقيع بالمفتاح نفسه، لذا أضف أسرار التوقيع
> قبل توزيع نسخة تنوي تحديثها لاحقًا.

لإصدار موسوم: ادفع وسمًا يبدأ بـ `v` (مثل `v1.0.0`) فيُرفق ملفا APK بصفحة
الإصدار تلقائيًا.

### محليًا

يلزم JDK 21 و Android SDK (‏`platforms;android-36` و `build-tools;36.0.0`) مع
ضبط `ANDROID_HOME`:

```bash
npm run android:apk     # ينتج android/app/build/outputs/apk/debug/app-debug.apk
npm run android:open    # لفتح المشروع في Android Studio
```

ثم ثبّت الملف على الجهاز: `adb install -r app-debug.apk`.

## بنية المشروع

```
src/
  core/      قاعدة البيانات (IndexedDB)، الإعدادات، الترجمة، الأصوات، أدوات عامة
  formats/   محلّل EPUB، محوّل PDF (pdf.js)، النصوص، والاستيراد وتوليد الأغلفة
  ui/        الأيقونات، الكتاب ثلاثي الأبعاد، التنبيهات والنوافذ
  views/     المكتبة، منصّة الكتاب، القارئ، التقسيم إلى صفحات، الإحصاءات، الإعدادات
  styles/    السمات والتصميم
android/     مشروع Capacitor لأندرويد
tools/       توليد الأيقونات وشاشات البدء
```

التخزين كله في IndexedDB: `books` (البيانات + ملف الكتاب + الغلاف)،
`annotations` (تظليلات وملاحظات وعلامات)، `sessions` (جلسات القراءة)،
و`settings`.

## English summary

Maktabate is an offline-first ebook reader whose library is a real 3D shelf:
books stand spine-out, clicking one pulls it off the shelf and rotates it to
show the cover, and starting to read swings the cover open into a two-page
spread with a genuine 3D page-turn. It reads EPUB, PDF, TXT, Markdown and HTML,
supports highlights, notes, bookmarks, diacritics-insensitive Arabic search,
read-aloud with word tracking, four themes, reading statistics, and full
RTL/LTR interfaces. Everything is stored locally in IndexedDB — no account, no
server. Ships as a PWA and as an Android APK built by GitHub Actions.
